# Releasebesluit SubsidieReady 1.0

14 november 2026: concept goedgekeurd, naam SubsidieReady en domein subsidieready.nl door eigenaar gekozen; publicatie verzocht. De publieke site is voorbereid voor indexering. De standalone distributie en private routes blijven noindex.

Code en lokale tests: zie `QA-v1.md`. Hosting, TLS, echte operatorconfiguratie, cron, backups en herstel zijn nog niet live geverifieerd. Voer de acceptatie in `HOSTINGER-LIVE.md` uit. Noem het project niet live totdat het echte domein gecontroleerd is.

De vorige conceptfase is historisch beschreven in `QA.md` en `PLAN.md`. Een groene CI-run blijft geen RVO-goedkeuring of garantie op juridische conformiteit.
